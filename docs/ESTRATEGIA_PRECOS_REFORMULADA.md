# 🎯 Estratégia de Preços Reformulada - Track OKR

## 📊 Funcionalidades Core do Sistema

### **O que o Track OKR oferece:**

✅ **Planejamento Anual**

- Criação de planejamentos estratégicos anuais
- Definição de metas organizacionais por período
- Gestão temporal de objetivos

✅ **Objetivos (Objectives)**

- Criação de objetivos vinculados aos planejamentos
- Organização hierárquica de metas
- Acompanhamento de status

✅ **Resultados-Chave (Key Results)**

- Definição de métricas mensuráveis
- Indicadores de progresso quantificáveis
- Acompanhamento de performance

✅ **Gestão de Times**

- Criação de equipes por área/departamento
- Atribuição de membros aos times
- Organização estrutural da empresa

✅ **Gestão de Usuários**

- Cadastro e autenticação de colaboradores
- Controle multi-tenant (isolamento por empresa)
- Perfis e permissões básicas

✅ **Dashboard Centralizado**

- Visão consolidada dos OKRs
- Métricas de progresso
- Interface intuitiva de acompanhamento

## 🎯 Implementação Técnica dos Limites

### **Sistema de Controle de Limites**

```typescript
interface PlanLimits {
  maxUsers: number;
  maxPlanners: number;
  maxTeams: number;
  maxObjectivesPerPlanner: number;
  maxKeyResultsPerObjective: number;
}

const PLAN_LIMITS = {
  trial: {
    maxUsers: 3,
    maxPlanners: 1,
    maxTeams: 2,
    maxObjectivesPerPlanner: 5,
    maxKeyResultsPerObjective: 3
  },
  essencial: {
    maxUsers: 10,
    maxPlanners: 1,
    maxTeams: 3,
    maxObjectivesPerPlanner: 15,
    maxKeyResultsPerObjective: 5
  },
  crescimento: {
    maxUsers: 50,
    maxPlanners: 3,
    maxTeams: 15,
    maxObjectivesPerPlanner: 50,
    maxKeyResultsPerObjective: 8
  },
  corporativo: {
    maxUsers: -1, // ilimitado
    maxPlanners: -1,
    maxTeams: -1,
    maxObjectivesPerPlanner: -1,
    maxKeyResultsPerObjective: -1
  }
};
```

### **Middleware de Validação**

```typescript
export const validatePlanLimitsMiddleware = async (req, res, next) => {
  const company = await getCompanyWithSubscription(req.companyId);
  const limits = PLAN_LIMITS[company.subscription.plan];

  // Validar limites específicos baseado na rota
  if (req.path.includes('/users') && req.method === 'POST') {
    const currentUsers = await getUserCount(req.companyId);
    if (currentUsers >= limits.maxUsers && limits.maxUsers !== -1) {
      return res.status(403).json({
        error: 'Limite de usuários atingido para seu plano'
      });
    }
  }

  // Outras validações...
  next();
};
```
